# Security Policy

Grit is a local Omarchy bar widget. It has no network access, collects
nothing, and phones nowhere. Its only file writes are the user's own lines
at `~/.local/state/omarchy/grit-custom.json`.

## Reporting a vulnerability

Please report privately rather than opening a public issue. Use GitHub's
private vulnerability reporting: the **Security** tab on this repo, then
**Report a vulnerability**.

You'll get an acknowledgement and a fix or explanation as soon as is
practical. Please hold off on public disclosure until it's resolved.
